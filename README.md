## ✨ Ключевые возможности проекта

- **Авторская дизайн-система в стиле Editorial Wellness**:
  - Изысканная палитра *Cream & Sage* (натуральный лен, шалфей, олива, темный уголь).
  - Высококлассная типографическая иерархия с засечками для заголовков и гротеском *Plus Jakarta Sans* для текста.
  - Полноэкранный hero-раздел с мягким светом и атмосферой безмятежности.
- **Интерактивная система бронирования сеансов**:
  - Модальное окно записи с выбором программы (*Deep Somatic Release, Sculpt & Flow Lymphatic, Sage & Warm Stone Journey, Craniosacral & Vagus Reset*).
  - Возможность выбора ведущего терапевта или персонального визита к основателю клиники Софии Мерсер.
  - Динамический выбор даты и времени с автоматическим расчётом доступных слотов.
  - Персонализированное подтверждение бронирования с фиксацией выбранного ритуала.
- **Презентация пространства и команды**:
  - Раздел об авторской методике и основателе клиники Софии Мерсер.
  - Галерея атмосферных интерьеров и велнес-зон.
  - Отзывы постоянных резидентов и лидеров индустрии.
- **Интерактивные компоненты**:
  - Раскрывающийся аккордеон с противопоказаниями и частыми вопросами (FAQ).
  - Интерактивная форма подписки на закрытые велнес-практики с мгновенной валидацией.
  - Плавное меню и навигация с автодоводкой скролла.

## 🚀 Локальный запуск

Сайт полностью автономен:

```bash
# Клонирование репозитория
git clone https://github.com/gennadijvaliev02-design/gemini.git

# Переход в директорию
cd gemini

# Запуск любого статического веб-сервера
python3 -m http.server 3000
# или
npx serve .
```

Открыть в браузере: `http://localhost:3000`.

## 🛠 Технологии

- **Стилизация**: Tailwind CSS (JIT, кастомные токены палитры Cream/Sage/Olive/Charcoal).
- **Типографика**: Google Fonts (Cormorant Garamond, Plus Jakarta Sans).
- **JavaScript**: ES6+ Vanilla JS без тяжелых зависимостей.
- **Публикация**: GitHub Pages.
